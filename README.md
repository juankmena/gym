# RecompFit JC

App inicial en Streamlit para seguimiento de recomposición corporal.

## Incluye
- Dashboard
- Rutina de 3 días
- Registro de series, peso, reps, RPE y dolor de hombro
- Temporizador de descanso
- Biblioteca de ejercicios
- Registro manual de Cubitt
- Gráficos de progreso
- Recomendaciones simples de progresión

## Instalación local
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Notas
Esta v1 está pensada para validar la lógica. En fases posteriores se pueden agregar imágenes/GIF reales, notificaciones PWA y mejor integración móvil.
